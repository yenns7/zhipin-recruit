## 3. 仍需明确保留的边界

- 当前更适合视为 demo / legacy correction path
- 用于演示环境里的轻量纠偏、旧数据修正、误推进说明
- 不应宣传为生产级回滚引擎

### 3.2 `offer / onboarded / rejected`

| 阶段 | 当前说明 |
|---|---|
| `offer` | 进入 Offer 阶段记录 |
| `onboarded` | 进入已入职终态记录 |
| `rejected` | 进入淘汰终态记录 |

这些阶段当前都**不是**完整业务治理闭环的代名词：

- `offer` 不等于完整审批流
- `onboarded` 不等于完整入职办理链路
- `rejected` 不等于完整拒绝原因治理与申诉修正闭环
