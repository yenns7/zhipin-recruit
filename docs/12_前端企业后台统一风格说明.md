# 前端企业后台统一风格说明

更新时间：2026-07-02

## 背景

智聘前端从偏轻量的卡片式界面，调整为更接近企业主数据后台的管理台风格。视觉参考为 `/Users/yenns/Downloads/global-id-mdp-front-master/screenshots` 中的后台页面截图。

本次不迁移参考项目技术栈，只复刻后台管理界面的视觉组织方式。

## 本次范围

- AppShell：统一为白色侧栏、顶部环境栏、页签栏、绿色激活态和企业后台导航密度。
- 简历库：统一首屏指标、筛选面板、候选人表格、分页/空状态和操作按钮样式。
- 岗位画像：统一首屏指标、招聘管理页签、筛选面板、岗位表格和右侧岗位详情面板。

## 保留约束

- 后端 API 不改。
- 路由权限不改。
- 角色逻辑不改。
- 不引入 Vue、Nuxt、Element、Arktos。
- 继续使用当前 React、Tailwind、lucide-react。

## 统一规范

- 页面壳子使用 `src/components/AppShell.tsx` 的企业后台布局。
- 通用展示组件放在 `src/components/enterprise/`，包括页面容器、指标首屏、搜索面板、表格卡片、空状态和详情面板。
- 主色使用企业绿色 `--enterprise-brand`，侧栏激活、主按钮、页签激活和强调链接保持一致。
- 表格统一为低圆角、浅灰表头、细边框、紧凑行距；候选人表格保留横向滚动，岗位表格使用更紧凑宽度适配右侧详情栏。
- 空状态统一使用图标、标题、说明和可选操作入口。
- 详情面板统一使用分组描述表和推荐动作卡片。

后续页面如果继续统一，优先复用 `src/components/enterprise/`，不要在业务页重复写独立后台样式。建议下一批覆盖：

- 候选人流程
- 数据看板
- AI 助手
- 系统设置
