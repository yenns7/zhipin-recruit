# Java Spring Boot + Vue 重构版口径修正 PRD

> 日期：2026-07-06
> 目标：统一重构版对外描述，纠正“全部 demo / in-memory”的错误口径，同时保留真实限制。

## 1. 背景

近期重构版文档和前端说明里，仍把部分已落库能力写成“demo / in-memory”。这会导致两类误判：

- 一类是**低估当前实现**：明明已经写入本地 H2，却被说成“刷新即丢、完全只是前端演示”。
- 另一类是**高估当前能力**：把“本地 H2 已持久化”误解成“已经是生产可用、真实第三方已接通”。

本 PRD 要解决的是口径清理，不新增接口，不改变模块边界。

## 2. 目标

- 把“已持久化到本地 H2”的能力说准确
- 把“仍是非生产 / 非真实第三方 / 非真实配置中心 / rule-based”的限制保留准确
- 给前端、文档、测试统一一套可复用表述

## 3. 非目标

- 不新增后端接口
- 不承诺真实第三方联通
- 不承诺生产级配置治理
- 不把 BI 演示值包装成真实业务统计
- 不把 Agent confirm-first 演示包装成真实自动执行

## 4. 当前事实口径

### 4.1 已持久化到本地 H2

- demo 登录账号与会话
- 系统治理参数、模型摘要、审计日志
- 通知待办的完成/归档覆盖状态
- 集成账号、扩展上下文、抓取任务
- 招聘主流程基础实体与部分最小读写接口

### 4.2 仍需保留的限制

- 环境仍是**非生产**
- 集成仍是**非真实第三方**
- 治理页仍是**非真实配置中心**
- BI 仍是**rule-based 演示指标**
- Agent 仍是**进程内存态 + confirm-first**
- 匹配推荐仍是**demo 数据**

## 5. 面向用户/协作者的推荐文案

### 5.1 推荐写法

- `已持久化到本地 H2 的演示状态`
- `本地重构库中的样例数据`
- `非生产联调环境`
- `未接真实第三方渠道`
- `未接真实配置中心`
- `rule-based 演示指标`
- `confirm-first，暂不直接执行真实写操作`

### 5.2 禁止写法

- `当前全部只是前端内存态`
- `刷新后全部恢复初始 demo`
- `已经接了真实第三方`
- `已经是可上线生产版`
- `系统治理已接配置中心`

## 6. 功能口径矩阵

| 能力 | 对外应如何描述 |
|---|---|
| 系统治理 | 已持久化到本地 H2 的治理壳层；非真实配置中心 |
| 通知待办 | 待办内容仍是演示生成，但 complete/archive 覆盖状态已落本地 H2 |
| 集成 | 账号、上下文、抓取任务样例已落本地 H2；不代表真实第三方打通 |
| BI | 页面展示重构版 rule-based 指标，用于壳层联调，不代表生产 BI |
| Agent | 会话仍在进程内存，写操作只给确认卡片，不执行真实业务写入 |
| 匹配 | 演示推荐数据可用于说明链路，不代表真实生产匹配结果 |

## 7. 验收标准

- 文档不再把上述已落库能力笼统写成 `demo / in-memory`
- 新文案保留 `非生产 / 非真实第三方 / 非真实配置中心 / rule-based / confirm-first` 等限制
- 不引入任何新接口或新业务动作
