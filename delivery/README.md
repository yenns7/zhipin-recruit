# 智聘（HireInsight）交付文档包

> **版本**: 1.0.0 | **最后更新**: 2026-07-09 | **状态**: 产品可试用（部分）

## 电梯简报

智聘是一个 AI 辅助招聘管理系统。四种角色（招聘专员、经理、面试官、管理员）围绕"岗位→候选人→面试→Offer"这条链路协作。Java + React 重构版刚完成前后端联调：typecheck 零错误、52 个契约测试全绿、285 个后端测试全过、npm run build 成功。后端 19 个 Controller 115 个端点全部可用。系统现在可以本地运行和产品试用，但还不是生产上线版本。

## 如何使用本交付文档包

阅读顺序建议：

1. **先读 01_产品方案.md** — 了解系统定位、角色分工和业务流程，建立全局认知
2. **再读 02_技术架构.md** — 理解技术选型、目录结构和关键设计决策
3. **按需查阅 03_接口文档.md** 和 **04_部署运维.md** — 开发者和运维人员的操作手册
4. **最后读 05_验收与试点说明.md** — 确认已知限制，按冒烟清单逐条验证

## 能力概览

### 当前系统能做什么 ✓

四角色完整登录/权限控制。岗位 CRUD。候选人列表/详情/改派/处置。简历上传（multipart，支持批量）与异步解析。Pipeline 看板（移动/修正/回退/历史）。面试（AI 出题评分/人工反馈/安排/指南）。Offer 创建/撤回/审批。BI 概览与 8 个细分维度。AI 助手 SSE 流式对话（8 种事件类型/session 管理）。BOSS 直聘 demo-stub。通知中心。审计日志。用户管理（创建/编辑/重置密码）。人才地图。所有端点统一返回 ApiResponse 信封。

### 当前系统不能做什么 ✗

BOSS 是 demo-stub（不连接真实 BOSS 直聘）。AI 无 key 自动降级 mock。简历解析依赖 LLM key。数据库迁移缺失 V1-V4、V6-V8。通知和处置响应字段是 snake_case（手写 Map）。三个前端方法（updateCandidateProfile、clarifyJob 等）后端未实现。没有生产级监控和灾备演练。全部限制见 [05_验收与试点说明.md](./05_验收与试点说明.md)。

## 与 Flask 旧版的关系

| 维度 | Flask 旧版 | Java 版（当前） |
|------|-----------|----------------|
| 技术栈 | Python Flask + Jinja2 模板 | Spring Boot 3.2 + React 18 |
| 架构 | 前后端同源托管 | 前后端分离 |
| API 契约 | snake_case | camelCase |
| 数据库 | 独立 | 独立 |
| 状态 | 技术验证原型，上线后退役 | 目标架构，当前交付版本 |
