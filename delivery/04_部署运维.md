# 部署与运维说明

## 端口一览

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端开发服务器 | 5173 | `npm run dev`，vite proxy `/api` → 8080 |
| Java 后端 | 8080 | Spring Boot，基础路径 `/api/v1` |
| PostgreSQL | 5432 | 数据库 hireinsight |
| Nginx (pilot) | 443 | 反代前端静态文件和 `/api/` |

## 本地开发环境搭建

### 前置条件

- Node.js（>=18）
- JDK 21 + Maven 3.9+
- Docker 或 Colima（跑 PostgreSQL）

### 启动 PostgreSQL

```bash
docker run --name hireinsight-java-postgres \
  -e POSTGRES_DB=hireinsight \
  -e POSTGRES_USER=hi \
  -e POSTGRES_PASSWORD=hipass \
  -p 5432:5432 \
  -d postgres:16-alpine
```

### 启动后端

```bash
cd rebuild/backend-java
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

`dev` profile 首次启动会自动建表（ddl-auto: update），并初始化 6 个演示账号（密码统一 `Zhipin2026`）：

- hr01@mvp.local / hr02@mvp.local / hr03@mvp.local（招聘专员）
- manager01@mvp.local / lead01@mvp.local（经理）
- interviewer01@mvp.local（面试官）
- admin01@mvp.local（管理员）

### 启动前端

```bash
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173` 即可使用。

### 测试

```bash
# 后端 285 个测试（H2 内存库，不需要本地 PostgreSQL）
cd rebuild/backend-java && mvn test

# 前端 53 个 vitest 单元测试 + 52 个契约测试
cd frontend && npm run test:vitest
```

## Pilot 真实用户试点部署

### 环境变量

从 `rebuild/backend-java/.env.pilot.example` 复制一份到安全位置：

```bash
cp rebuild/backend-java/.env.pilot.example /etc/hireinsight/hireinsight-pilot.env
chmod 600 /etc/hireinsight/hireinsight-pilot.env
```

**必须修改的项**：

- `JWT_SECRET`：至少 32 字符强随机串，用 `python3 -c "import secrets; print(secrets.token_urlsafe(48))"` 生成
- `DATABASE_PASSWORD`：不要用 `hipass`
- `CORS_ALLOWED_ORIGINS`：写真实前端域名，不要 `*`
- `UPLOAD_FOLDER`：持久目录，如 `/srv/hireinsight/uploads`，不要 `/tmp`
- `FIELD_ENCRYPTION_KEY`：`openssl rand -hex 32` 生成
- `PUBLIC_REGISTRATION_ENABLED`：false

**可选修改**：

- `LLM_API_KEY`：配置后启用真实 AI 能力（面试出题/评分、简历解析），不配则自动 mock
- `BOSS_DEMO_MODE`：默认 true（demo-stub），设为 false 需同时配 `BOSS_CLI_PATH`

### 启动

```bash
cd rebuild/backend-java
mvn spring-boot:run -Dspring-boot.run.profiles=pilot
```

建议用 systemd 管理。示例 service 文件见 `rebuild/DEPLOYMENT.md`。

### PilotReadinessValidator 校验项

`pilot` profile 启动时自动检查以下项，不通过则拒绝启动：

1. `dev` profile 不能同时激活
2. JWT_SECRET 长度 >= 32 且非默认弱值（`change-me-in-prod-use-32-byte-secret` 等）
3. DATABASE_PASSWORD 不能是 `hipass`
4. CORS_ALLOWED_ORIGINS 不能包含 `*`
5. PUBLIC_REGISTRATION_ENABLED 必须为 false
6. UPLOAD_FOLDER 是持久目录，不在 `/tmp` 下
7. FIELD_ENCRYPTION_KEY 已设置且长度 >= 16
8. 数据库中不能存在 demo 账号（`*@hireinsight.local`、`*@mvp.local`）

## 备份与恢复

备份脚本：`rebuild/scripts/backup_pilot_data.py`

```bash
# 预演
python3 rebuild/scripts/backup_pilot_data.py --dry-run
# 执行备份
python3 rebuild/scripts/backup_pilot_data.py
```

备份内容包括：
- `database.dump`（pg_dump）
- `uploads.tar.gz`
- `manifest.json`

恢复脚本：`rebuild/scripts/restore_pilot_data.py`

```bash
# 预演
python3 rebuild/scripts/restore_pilot_data.py --backup-dir /srv/hireinsight/backups/<timestamp>
# 确认执行
python3 rebuild/scripts/restore_pilot_data.py --backup-dir /srv/hireinsight/backups/<timestamp> --confirm
```

建议每天至少做一次 `pg_dump` 备份，保留 7 天以上。

## 已知部署风险

1. **Flyway 迁移脚本跳号**：缺 V1-V4、V6-V8。现有 V5、V9-V18。新建迁移不要按编号猜测顺序，要看实际 `created_at`。
2. **BOSS demo 重启丢失**：默认 BOSS_DEMO_MODE=true，数据存内存（ConcurrentHashMap），重启后丢失。
3. **AI 无 key 降级**：LLM_API_KEY 为空时，AI 功能返回 mock 响应，不会报错但数据是假的。
4. **登录限流 5 次/60 秒**：试试点时连续输错密码会被短暂锁定，返回 429。
5. **上传文件默认存 `/tmp/hireinsight_uploads`**：生产部署必须改 `UPLOAD_FOLDER`。
6. **没有生产级监控**：当前只有 `/api/v1/health` 健康检查和 Spring Boot Actuator（未配置）。没有告警、没有 APM。
7. **没有灾备演练**：备份脚本有，但没经过真实恢复演练。

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 后端启动时报数据库连接失败 | PostgreSQL 未启动或端口冲突 | 检查 `docker ps`，确认 5432 端口未被占用 |
| 登录返回 429 | 连续输错密码触发限流 | 等待 60 秒后重试，或重启后端清空限流记录 |
| AI 面试/简历解析返回假数据 | LLM_API_KEY 未配置 | 参考 .env.pilot.example 配置 key |
| 前端页面空白/接口 404 | 后端未启动或 proxy 配置错误 | 检查 `http://localhost:8080/api/v1/health` 是否返回 UP |
| Flyway 迁移报错 | 数据库 schema 版本不一致 | 检查 `flyway_schema_history` 表，确认已有版本，必要时 `mvn flyway:repair` |
| Pilot 启动被拒绝 | PilotReadinessValidator 校验不通过 | 检查环境变量：JWT_SECRET 长度、DATABASE_PASSWORD 非 hipass 等 |
